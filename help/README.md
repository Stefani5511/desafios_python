# Help!

## Descrição

O objetivo é calcular o placar de uma competição de programação com base nas submissões realizadas pelos times.

Cada submissão contém a identificação do problema, o tempo em minutos e o resultado do julgamento, que pode ser `correct` (correto) ou `incorrect` (incorreto).

A pontuação considera a quantidade de problemas resolvidos e o tempo total, acrescentando 20 minutos de penalidade para cada submissão incorreta de um problema que posteriormente foi resolvido corretamente.
