# Esquerda Volver

## Descrição

Um recruta deve executar uma sequência de comandos para virar à esquerda ou à direita. Inicialmente, ele está voltado para o norte.

Cada comando `E` representa um quarto de volta à esquerda, e cada comando `D` representa um quarto de volta à direita.

O objetivo é determinar a direção final para a qual o recruta estará voltado após executar todos os comandos.
