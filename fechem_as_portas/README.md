# Fechem as Portas!

## Descrição

Madame Beauvoir possui uma mansão com N quartos, numerados de 1 a N. Cada descendente troca o estado das portas cujos números são múltiplos do seu identificador.

Todas as portas começam fechadas, e cada descendente entra uma única vez na mansão.

O objetivo é descobrir quais portas estarão abertas após todos os descendentes realizarem suas trocas.
